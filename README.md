
# FaceExpressionDetection

A Facial Expression Recognition project using a Convolutional Neural Network (CNN) trained on the FER-2013 dataset.

## Features

- Facial expression classification into seven categories
- CNN-based image classification using TensorFlow and Keras
- Image prediction using OpenCV
- Interactive web interface using Streamlit
- Model evaluation with accuracy, classification report, and confusion matrix

## Expression Categories

- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

## Tech Stack

Python, TensorFlow, Keras, NumPy, Scikit-learn, OpenCV, Matplotlib, Streamlit


## Dataset

Download the FER-2013 dataset from Kaggle:

https://www.kaggle.com/datasets/msambare/fer2013


## Disclaimer

Predictions are estimates based on facial image patterns and should not be treated as definitive measurements of a person's emotional state.
